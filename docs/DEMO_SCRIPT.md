# Level 4 Demo Script

Target length: 2–4 minutes.

1. Open the hosted dApp and show Lace/1AM connect on Midnight Preview.
2. Deploy the voting contract and copy the contract address into the README later.
3. Register the demo voter Merkle root.
4. Create and open a proposal; show status `active`.
5. Cast a Yes vote with Voter 1; show proving stages and refreshed public tally.
6. Retry the same credential; show `NULLIFIER_SPENT`.
7. Optionally vote with Voter 2, then close/finalize and show Passed/Failed/QuorumFail.
8. End on the Privacy panel: what observers learn vs what stays private.
